# 河北大学《C程序设计》实验指导书目录结构与全量题目核对清单

本手册收录河北大学电子信息工程学院《C程序设计》实验指导书的规范目录树结构、各小题任务点及防漏写/防多写核对清单（Checklist）。

---

## 核心防漏写、防乱序原则

1. **不可合并题目**：实验指导书中每一个带有“★”或“（1）（2）”的小任务，都代表一个独立的控制台验证或思考点，必须作为独立的小标题或表格条目作答。
2. **不可自拟结构**：严格遵守指导书的层级顺序（实验一 -> 实验二 -> 实验三），内部序号必须 1:1 对齐指导书，不可颠倒顺序。
3. **不可无中生有（防多写）**：只解答指导书要求的范围，不要自行补充不相关的操作系统原理、汇编语言分析或复杂的拓展推导。

### 实验三：顺序结构程序设计

| 序号 | 题目 / 任务描述 | 重点观察与记录内容 | 呈现形式 |
| :---: | :--- | :--- | :---: |
| 3.1.1 | **★ 10 = a 错误** | 常量 10 属于右值（rvalue），不能作为左值（lvalue）被赋值，编译器报错 `error: lvalue required as left operand of assignment`。 | 报错原因分析 |
| 3.1.2 | **★ a == 10 赋值误写为关系运算** | 把赋值 `=` 写成关系判断 `==`，语句只产生布尔值未修改变量值，属于常见逻辑失误。 | 逻辑漏洞说明 |
| 3.1.3 | **★ 1/2 与 1.0/2 对比** | `1/2` 是整数相除截断为 `0`；`1.0/2` 自动提升为浮点除法结果为 `0.5`。 | 运算对比表 |
| 3.1.4 | **★ 13 % 5 取模运算** | 取模求余数运算结果为 `3`，总结两操作数必须均为整数的语法规则。 | 结果与语法点 |
| 3.1.5 | **★ a = a++ 与 a = ++a 测试** | 自增运算：`a++` 先用后加，`++a` 先加后用；在复杂表达式中可能导致未定义行为（UB）。 | 表达式分析 |
| 3.1.6 | **★ b = 1.0f / 3 浮点精度观察** | float 单精度有效数字 6~7 位，观察输出 `0.333333` 与舍入误差。 | 精度输出记录 |
| 3.1.7 | **★ c = 65 与 c = 321 字符赋值** | `c = 65` 对应字符 `'A'`；`c = 321` 超出 char 范围（[-128, 127] 或 [0, 255]），发生模 256 截断：$321 - 256 = 65$，依然输出 `'A'`。 | **字符截断与溢出表** |
| 3.1.8 | **★ 转义字符 '\101'、'\x61'、'\\'** | `\101` 八进制转十进制 65 ('A')；`\x61` 十六进制转十进制 97 ('a')；`\\` 转义输出反斜杠字符。 | **转义字符对照表** |
| 3.1.9 | **★ 总结赋值、优先级与类型转换** | 总结算术运算符优先级、自动类型转换层级（char -> int -> float -> double）与强制类型转换。 | 综合总结 |
| 3.2.1 | **★ 华氏温度转摄氏温度（temp_convert.c）** | 公式 $C = \frac{5}{9}(F - 32)$，注意必须写 `5.0 / 9.0 * (F - 32.0)` 避免整数除法 $5/9=0$。 | 完整源码与自测 |
